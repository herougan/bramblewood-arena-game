## Import a chosen candidate (one command)
    python3 tools/art14_import.py windfall 2
    python3 assemble_arena.py && mv bramblewood-arena.html index.html

It writes `art/fields/windfall.png` (128 px nearest to 256 px, 256-colour palette, the same finish as ART7/ART13). `FIELD_ART.windfall` in `arena_app.js` already points there, so no code change. Then view it in the game (`tools/shot.py`, Windfall Environment card, 390 px) and add a CHANGELOG line.

## How the images were made and kept
Generated in the owner's PixelLab session (existing credits, nothing bought). Two extra generations were started by mistake while the prompt box still held an older prompt (they show in the gallery as bumblebee grids). The grid was shown at 6x in the browser and sampled at pixel centres from a screenshot (the PixelLab download button was not used), then snapped to 48 colours, so thin wind streaks are slightly warmer than in the site's preview. Each cell is 127 px in the gallery grid and was stretched to 128 by one repeated column.
