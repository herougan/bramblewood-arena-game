# Easter-egg card art briefs (2026-10-19, package EE)

One NightCafe prompt per Easter-egg card. **Nothing was generated and no credits were spent.** Until art is made, each card shows its emoji placeholder (in brackets below).

Rules for these prompts:
- Every prompt is original. It never names a source game, studio or character.
- Every prompt includes a background.
- These words are kept out: "no clothes", weapon words, "spiked", "studded", "monitor", "sperm" and "corpse".
- The prompts follow `docs/art-style-prompts.md` (cosy woodland pixel art, one bright accent) and end with "detailed pixel art, full background", like the pool cards' prompts.
