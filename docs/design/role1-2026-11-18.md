# ROLE1: card roles on the Maps 0-20 lists (analysis, 2026-11-18)

Owner 2026-11-18 20:42: does each map's card list keep "some sort of balance - strong creatures, cute, resource etc" after REDESIGN3 v2 (folded by FOLD6)?

**Analysis and proposals only. Nothing applied.** Machine copy: `docs/design/role1-2026-11-18.json`. Generator: `node tools/role1/gen.js` (read-only; rewrites the .json and this page).

- **Inputs:** `canonical/map-pools.json` MAP lists of Maps 0-20 (a card counts on every list that holds it; "home" = its first list), `canonical/cards.json` (after FOLD6, SKAUD1, CONTENT13, DATAFIX), REDESIGN3 v2 focus skills (`docs/design/redesign3-2026-11-17.json`).
- **Role rules (from data):**
  - Strong: top third of the list by power = the budget left side x1 (2A + H + S, x the miss multiplier) from tools/skill_costs.js budget() at Level 1 at the card's home (first) list; the #1 is the map peak.
  - Cute: kind baby; a young animal by id (kit, pup, cub, calf, fawn, chick, duckling, hatchling, fry, sprout, grub ...); a small animal by id (shrew, mouse, chipmunk, vole, pika, rabbit, hare, hedgehog, squirrel, meerkat, robin ...); or, for a card first listed on Maps 0-5, the style guide's Cute genre (starter/common, Attack + Health under 15). Missing Cute flagged on Maps 0-5 only.
  - Resource: foraging, delivery, forestry, bounty, hoard, stonecutter, pickpocket, plunder, felling, pearl, onReadyGold, onSpawnGold, gainGold, or a trigger that gains a resource (Lumber ...).
  - Support: nursing, healing, herbalist, cure, inspiring, repair, herald, fletcher, broodkeeper, venomMaster, packLeader, armourer, banner, warcry, or a trigger that shields / heals / buffs allies.
  - Ranged: any skill whose delivery is "ranged" in canonical/skill-delivery.json (arrows, bolts, Snipe, Twin Shot, Electricity, powders ...).
  - Defender: guardian, taunt, armor, sturdy, shield, bulwark, helmet, fortify, shieldwall (Thorns not counted).
  - Focus: the map's REDESIGN3 v2 focus skills shown at the card's base level (tools/redesign3/lib3.js metSkills); 2+ carriers wanted (Bloom, Meiosis: one allowed).
- **Role rules already in the data:** only BAL9 JJ28 (a Guardian / Taunt / Bulwark defender on every main map 1-19, `tests/bal9-2026-11-02.js`). Card counts and rarity mixes were the only other things REDESIGN3 kept.
