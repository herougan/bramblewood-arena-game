# CPU2 (2026-11-28): how well the CPU pilots the Maps 0-20 design space (read-only study)

Proposal only: no code changed. The engine wins over this page. Sources: `bramblewood-engine.js` AI region (L9129-9770, `aiDevourPlan` L2361), `docs/project-state.md` section 6, ARCHETYPES1. Claims below come from reading and grep, not from a run; the benches in part 3 would confirm each.

## 1. Who decides what

- **Level first.** `cpuAiLevelForNode` (see `tools/skirmish_pass.js` header): road fights on Maps 0-20 run the **Basic** CPU (aiLevel 0); Smart only for elite / boss from Map 5; Smartest from Map 21. So the turn planner (`planOn = aiSmart() && slotMode`, `aiPlanPlay`) and the smartest slot scorer (`aiSlotScorerSmartest`) do not run in most road fights. Basic uses `situational()` for the card, then `aiChooseSlot`'s older trade check (75% of the time) plus noise `rnd()*1.5`.
- **Card choice:** `cardValue` = Attack + 0.45 Health + 1.5 per skill key + 2 per cost. Every skill counts the same; `situational()` adds only stat-shaped nudges (walls under pressure, damage when the foe is low, anti-air, Tide, wind, Prayer).
- **Lane:** `aiChooseSlot` / `aiSlotScorerSmartest` / `aiLaneBonus` (middle lanes) / `aiBonusVs`.
- **Pitch:** `aiUsefulNow`, `aiPitch`, `pitchPick`, `aiSavePlan`, `aiReserveOf`.
- **Targets:** On Play and skill targets are random by owner rule (`resolveGeneralTarget0`, 2026-11-09), so the CPU cannot "choose" them; that is design, not a gap.

## 2. Archetype verdicts

| Archetype | CPU pilots it? | Why |
|---|---|---|
| A1 Early aggro | Partly | Ready bodies get a kill / block score (`aiBestKillNow`, trade check), so Wait 0 rushes play. It never reads Pounce or Inspiring as tempo: they are 1.5 each in `cardValue`. |
| A2 Reactive "protect this turn" | No | Nothing reads a foe at Wait 1 (`aiSwingOdds` is 0 for Waiting units; the project-state note says so). A Shield-all or Stun card is played for its stat value, not held for the round. Spells are only `hasten`/`mend`/`sap`. |
| A3 Midrange value | Mostly | Walls are favoured when pressed. Foraging, Meiosis, Intimidate carry no timing. |
| A4 Tribe engines | Weak | Swarm / Kin value is not read; Bee Warden is played as a 1/2 body into any lane, where a Pounce kills it. |
| A5 Death engine | No | `aiDoomed` asks only "does the facer kill it"; it never asks "I want it to die". `aiSacrificePick` is the lone death-aware code and covers Dark Summon only. Harbinger, Carrion, Broodmother, Sulfur Cinder Moth score as plain stats. |
| A6 Poison / Bleed | Partly | `aiBonusVs` knows Detonate, Powders (`aiPowderVs`); no Bleed-on-held-unit awareness (COMBO1 note A). |
| A7 Late control | Partly | `aiSavePlan` gathers for a big card (2 turns max), good for Wait 3+ payoffs; no read of On Ready forecasts or Guardians as "buy rounds". |
| A8 Ranged chip | Weak | Archers go to the middle lanes like any body; no "behind a Guardian" rule. |

## 3. Ignored or misused skills and triggers

- **On Death (Rend, Sting, Alarm, Cache, Brood):** no AI term reads `onDeath`. Cheap bodies with a death payoff are not sent to trade, and the CPU does not avoid or force the killing blow. A killer's Rend or Poisonous is not priced into `aiBestKillNow`.
- **On Play ⬆️:** the CPU holds a Shield-all or Stun card for no moment; it plays it by `cardValue`.
- **Wet + shock chains (Map 9), Dogfighter, Warning Colours:** grep finds none in the AI regions. Dogfighter is only in damage code (L6736). Warning Colours (`wcDeath`, L4525) is applied after the fact, so the CPU attacks a 💀 Warning Colours unit with its best Ready body and takes the poison. Wet is never set up before a shock card.
- **Resource skills:** pitch is solid (EN8, AI3, ENG14); Forestry / Lumber makers are not valued above plain stats; leaders are never saved for (LEAD-4).
- **Ranked by cost to the player experience:** the CPU is easy to bait with death cards and easy to outplay with a held answer.

## 4. Ranked CPU fixes

Measure each with paired seeds: `node tools/skirmish_pass.js measure 40 --tag=before` then `--tag=after` (same seeds, 9100 + 37g), Maps 0-20 only, plus a 200-game bench of the reference deck against the changed CPU. Report road fights in band / within 10 / beyond 20.

| # | Function | Change | Expected effect | Measure |
|---|---|---|---|---|
| 1 | `cpuAiLevelForNode` / `aiTakeTurnOnce` | Run the turn planner (`planOn`) for Basic too, with its noise kept, or a "Smart-lite" level | Biggest lever: fixes lane choice on every road fight. Moves the road (CPU stronger). | `measure` on Maps 0-20; expect CPU +3-6 points |
| 2 | `cardValue` / `situational` | Price skills by kind: Pounce, Inspiring, Guardian, Swarm per Kin, Harbinger higher than a generic 1.5 | Early aggro and tribe decks play the right body first | Paired seeds, tribe-heavy maps 0-8 |
| 3 | `aiDoomed`, `aiBestKillNow` | Read `onDeath` (Rend, Sting, Poisonous, Warning Colours) as a cost of the kill, and as a gain for its own unit | Stops feeding Rend units; Brood / Alarm cards pay | Bench: Sting / Rend card vs CPU, kill rate |
| 4 | `aiPlanPlay` (new hold term) | Hold ⬆️ Shield-all / Stun / +Wait cards while no foe is at Wait 1, play them the round one is | CPU decks with reactive cards (ARCH1-4) become real | Bench: Hedgehog Matron, Ash Cloud Condor decks |
| 5 | `aiSlotScorerSmartest` | Wet then shock: prefer a slot facing a Wet unit for a shock card; Dogfighter prefers a Flying facer | Closes Map 9-10 gaps | Map 9 / 10 paired seeds |
| 6 | `aiSlotScorerSmartest` | Guardian-behind term for archers and engines (1/2 bodies) | Bee Warden, Fletcher stop dying to Pounce | Maps 0-8 seeds |
| 7 | `aiSavePlan` / `aiLeaderToGather` | Save Lumber for the leader (LEAD-4) | Leaders appear in CPU fights | Count leader plays per 100 games |

Ship #1 alone first: it is the largest effect and touches balance for every map.
