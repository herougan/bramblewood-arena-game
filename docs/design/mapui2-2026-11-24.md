## Colour rule (one set)
| Tile | Meaning | Look |
|---|---|---|
| NEW! | first met on this map, in the owner's table row | red |
| To add | in the table row, on no listed card | red left, blue right |
| To remove | NEW! here, in neither the row nor its Special / Faction column | black left, red right |
| Suggested / Counter / Codex | on no listed card, recommended | blue |
| Carried | a listed card has it (earlier maps' skills, the side-map and special skills) | grey |

Order: red, red / blue, blue, grey (main-list skills, then side maps and specials). A skill a listed card carries wears no Suggested, Counter or Codex pill.

The pill now goes only to tiles no listed card carries; a map with a table row also drops the Sugg. Intro list (`ui30McSugg`).

## Level bar
Levels 0-15. 0 and 11-15 dark. Gold = `mapui2Range(n)`: the whole levels from the lowest to the highest of `referencePlayerLevel(n)` and the enemy's (`EARLY_ENEMY_LEVEL` on Maps 0-1, else `roadEnemyScheduleLevel(n, 0)` and `(n, 1)`). Map 0: 0; Map 1: 0-1; Maps 2-4: 0-1; Map 5: 0-2. Default pick = the highest gold level. A pick (`mapui2Pick`) reopens the window at that level: skills = those each card has learnt by it (never below the card's own base level; `mapui2AtLevel`), tiles = `eng23MapDef(id, defs, level)`. The Prospects view's head carries the same bar. Rewards list the map's own fights only.
