# PACKSET1 (2026-11-22): Pack Editor "All cards" panels

Owner 22:41, items 1, 2, 4, 5, 6. Admin only. Code: the `PACKSET1` block after `packEditorExtrasEdit` in `arena_app.js` (`packset*`), the early lines at `basicPackTierOf`.

## What the owner sees
Admin tab, Pack editor, under the pack cards: **All cards (0-20)** and **All cards (20-40)** (Packs 1-3 / 4-6). Each opens a Map-cards-style window:
1. **Tutorial** (T-1/T-2), then per faction (Otters, Hummingbirds): the starter deck now, then Claude's tutorial suggestions with YES / NO and a **n / 16** counter (YES count). (0-20 panel only.)
2. **Base**, **Faction** sections (0-20 panel only).
3. One section per main map of the panel: its Yes picks plus its side maps' Yes (map order), then the bonus cards he said YES to.
4. **Bonus (pack-only)**: Claude's suggestions for the panel's maps with YES / NO (default No, greyed, as the map picks).

Tile = the map-cards tile (art, stats, budget %, Baby, Starter, pack) + pills: Map N, AI pick, faction, Skirmish (in any fight deck, reward, tower / ambush deck, or a map-source card), x-uses. Right-click or the ⋯ button: map picker (`PACKSET_MENU`, add entries there for REWARD3). Header: cards per pack, Default cuts.

## Pack cuts
`packsetModel(pk).seq` = the map-order cards. `packsetStarts` = start index of each pack: the owner's cut cards, else the first card whose map is in the pack's 7 maps (`packMapRange`). `packsetSetCut(pk, t, id)`: refuses a cut at or before the pack before it; pushes later cuts on (never empty-before, never backwards).

## Data and saving
`packsetState` = `{yes, no, map, tyes, cuts, tiers, localAt}`: `localStorage bw_packset1_v1` and the admin row `__cfg:pack-set` (`packsetPublish`, written by the app when the owner clicks, 700 ms debounce, never SQL; `applyCloudPackSet` reads it, newer wins as the map picks do). `tiers` (card -> pack) is a snapshot worked out in `packsetRecompute` at each change, so players need only the row: `basicPackTierOf` returns it for a card with an entry (a map-list pack card or a YES bonus card), else today's rule (`basicPackTier0`). Empty state = today's pools. `packPoolOf` / `packTierCardIds` / the roll read `basicPackTierOf`, so they follow.

## Suggestions
`node tools/packset1_suggest.js` writes `canonical/pack-bonus-suggestions.json`: bonus 3 per map (Maps 0-24; 63 for 0-20; 2 asked), from cards on no list, not an owner Yes, in no node deck or reward and in no tower / ambush / tutorial deck, no token, Easter egg, faction, Baby, equipment; scored by biome (`unit-themes`), the animal families on the map's lists and the map's budget step. Tutorial: 40 otters, 26 hummingbirds (low rarity, cost <= 3, base / faction / unlisted or listed commons fitting the animals). Baked in by `assemble_arena.py` (`__PACK_BONUS__`).

`tiers` are a snapshot of the map order at the owner's last change in the panel; a later change of a map's Yes list shows in the panel at once but reaches the packs at his next click there. The sub line says ▸2 / ▸3 on both panels (the 20-40 buttons read ▸5 / ▸6).
