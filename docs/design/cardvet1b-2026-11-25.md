# CARDVET1b: vet of the cards on Maps 7-13 (2026-11-25)

Owner 2026-11-25 00:22: "Vet through each card after - if it doesnt fit the theme - for example a late-game animal with too simple an effect - maybe we have to change it or consider doing trigger->actions instead ... we want more active skills (on play or immediately this combat, after play e.g. 0 wait) - allows players to surprise each other etc. High wait cards are like building for payoffs. Change the card designs for cards with skills we dont use for 0-20 anymore. ... can we do more realistic animals b4 the elemental animals and magical ones ... The art would have to be generically menacing and not too grassy tho." Same method as CARDVET1a (`docs/design/cardvet1a-2026-11-25.md`).

Package files: `tools/cardvet1b_2026_11_25.js` (change list `DES`, stat fit, then `tools/lvl10/gen_2026_11_18.js` per card with env `CARDVET_CORE` for the Level 1 core), `tools/i18n_2026_11_25_cardvet1b.json` (3 names, 5 flavours, 12 packs), `docs/art/real1-requests.md`. Rows read from `MAP_FOCUS_SKILLS` and `MAP_SPECIAL_SKILL_NAMES`.
