Measurement only: no card, budget, engine or decision changed. Owner asks, 11-14: 11:11 (more robust skill weights, several ways of building the field; decouple trigger from action), 11:25 (Bramblewood's own trigger and action tables; the reference is in `reference-hearthstone-2014.md`, a thinking tool only, 11:31), 11:31 (how many named skills a player meets on Maps 0-20; near-duplicates, listed only).

## Method
- The skill canon's paired design (`tools/skill_canon_2026_10_31.js`): six vanilla carriers (the canon's pick: house-cat, bramblewood-lynx, blessed-avatar, stable-colt, rivergate-recruit, lucky-hopper: a Common and an Uncommon / Rare hitter, balanced and wall), each as a slot of 6 copies in a 20-card deck; every variant plays the same fights (decks, field, engine seed). Brambles 15 (the road's).
- Per carrier: base, +1 Attack, +3 Health, the placebo (a key the engine ignores; the CPU values cards by key count), each test. Worth = gain / ruler, ruler = (gain(+1 A) + gain(+3 H)) / 6 = win rate per budget point of 3A + H. Placebo gain taken off once a key. 95% intervals: bootstrap over fights (ruler and test resampled together). Price = the budget's cap-1 left side, variant less carrier (`tools/skill_costs.js` on `bramblewood-budget.js`).
- Size: 100 paired fights x 6 carriers a variant (600 carrier-fights a skill a context). Part A about 22,800 games a context x 7; Part B 48,000 a context x 2 (g1, ref; the base variants shared with Part A); B2 9,600 (g1); fire counts 7,500 a context x 3 (g1, ref, van, 50 fights). About 287,000 games, one thread, 11:23-14:20.

### The seven contexts (why)
| Code | Decks | Field | Level | Why |
|---|---|---|---|---|
| g1 | random legal decks from every fieldable card | every road fight's field (410) | 1 | the pipeline's own context, comparable to `measures.json` |
| g10 | same | same | 10 | late levels: bigger bodies, fixed-number skills shrink |
| van | vanilla cards only, both sides | none | 1 | the skill alone, no synergy or field |
| nof | as g1 | none (all day) | 1 | field effects removed |
| tide | as g1 | the 35 tide fields of Maps 0-20 (Flood / Ebb) | 1 | tide skills |
| dark | as g1 | the 37 dark / night fields of Maps 0-20 | 1 | night and dark skills, misses in the dark |
| ref | opponent = one of the 230 PRO / BPRO decks of Maps 0-20 (main + side maps), its map's field; rest from that map's pool | the PRO's field | 1 | the reference decks the road is tuned against |

Rulers: one budget point = 2.3 (dark, g10) to 3.5 (ref) win-rate points; each about +-30% (95%), carried in every worth interval.

## Part B: trigger x action, decoupled
Design: the carriers get one trigger entry; 10 triggers x 8 actions = 80 pairs, each measured as a worth (same ruler). Triggers: On Spawn, On Turn Start (perTurn), On Round Start, On Attack, On Attacked, On Death, On Kill, On Ally Die, On Enemy Spawn, On Ally Played. Actions: Deal 2 (random enemy), Poison 1 (random enemy), Heal 2 (self), +1 Attack (self), +2 Health (self), Shield 2 (self), Draw 1, +1 Lumber. Then fitted: additive (W = mu + a_t + b_a), multiplicative (W = f_t x g_a, On Spawn = 1), multiplicative + action offset. Weighted by 1/se².

|---|---|---|---|
| additive, all cells | 0.83 | 3.96 | 8 |

| **multiplicative, rule-empty cells out** | **0.975** | **0.52** | **0** |

Rule-empty cells (5 of 80): a self action On Death (Heal, +Attack, Shield: 0.00 measured; the unit is gone) and Heal On Spawn (full Health: 0.05). Leave those out and **trigger x action factors within noise**: worth = trigger multiplier x action base value. Pairs that do not factor (real interactions):
- **On Death + Health buff on itself keeps the unit alive**: +2 Health 5.2 points, +4 Health 5.1 (the amount does not matter; it acts as a revive). Likely an engine rule gap (Health raised above 0 inside the death pass); for the engine package to check.
- **Draw saturates** on repeating triggers: On Turn Start Draw 1 4.3 (price 12.3), On Ally Played 3.6 (10.25), On Attacked 2.6 (7.8). A hand only holds so much.
- **Heal** needs damage to heal: 0 On Spawn, about 2.5-2.9 on repeating triggers (budget 0.42-1.2).
- On Turn Start and On Round Start played identical games in every cell (budget 3 vs 3.5).

## Proposals (text only; budget changes are owner calls)
1. **Trigger weights from frequency.** Replace the trigger weights' ratios with the measured multipliers (mean of g1 and ref), or the rule weight = 0.6 x fires per copy played (On Spawn 1), fires from `fires-*.json`. Biggest moves against today's ratios: On Enemy Spawn 2.86 -> 0.08, On Kill 1.33 -> 0.42, On Death 0.76 -> 0.26 (non-self actions), On Attacked 1.81 -> 1.2, On Turn Start 2.86 -> 2.2, On Ally Played 2.38 -> 1.7; On Attack 1.29 -> 1.85 goes up.
2. **Action base values** (one On Play firing, mean of g1 and ref): Deal damage about 1.5 a point (now 0.4), +1 Attack 2.8, +2 Health 1.9, Shield 2 1.8, Heal 2 1.4 where it can heal, Poison 1 1.5, Draw 1 2.0, +1 Lumber 2.1. The pair table (`pairs` mults) can then go, but the rule-empty and saturating pairs below.
