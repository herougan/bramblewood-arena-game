# Pool reference (ref-pool), 2026-10-27

Package BAL6 (K17). Owner 10-27 11:22: "make the best deck we can given the deck unlocks and random 5 common cards unlocked every map (from packs). Then we have a good pool".

Per main map, the deck optimizer's best deck (`tools/opt/deckopt.js --mode ref-pool`, its gauntlet: the map's fight decks and reference decks in a fair mirror under each fight's field, plus the road fights as the game builds them) from the cards a player holds arriving there. The pool: the starter cards (the starter reference deck and every Base card), every earlier main map's first-clear cards, the faction rewards received by then (Otters, the faction track simulation, seed 7) and 5 random Common pack cards per map cleared (seeded). Any pool card up to its rarity's copy cap. Level: the Map reference's (`referencePlayerLevel`). Data: `docs/balance/ref/ref-pool-pools.json`, `docs/balance/ref/ref-pool.json`, `docs/balance/bal6-ref-vs-optimum-2026-10-27.json`.
