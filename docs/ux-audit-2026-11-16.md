# UX audit, 2026-11-16 (package UX3)

Method: Playwright on the built `index.html`, 390 px and 1280 px, light and dark; German and Tamil at 390 px. Screens: home, map, deck (Camp), Codex, Forge, shop, nest, profile, settings, a fight, its Victory screen. An automatic scan of every visible element for right-edge overflow, buttons under 36 px, clipped text and page errors. Shots: `docs/screens/ux3/`.
Not walked: first-launch splash, pack opening (opened with a stub, not inspected), conquest node panel, deck editor popup, Raid and Arena.

Clean: no horizontal page scroll on any screen, width or language. The only console errors were blocked network loads (the sandbox is offline), no script errors.
