## How it works

The code is in `bramblewood-i18n.js`.

- **Page translator.** While a non-English language is active, it watches the page. It swaps any text, title, label or placeholder whose English matches a pack entry. It ignores leading emoji and symbols, and keeps them.
  - Buttons and labels translate without anyone touching the code that draws them.
  - Switching back to English restores the originals.
- **Not translated:** card names (`.nm`), anything inside `translate="no"`, inputs and text areas.
- **`i18('Need {n} more 🍁', {n})` in code:** for sentences with numbers or names in them. The page translator can't match those, because the English varies.
- **Packs:** `lang/<code>.json` holds `{"English": "translation"}`.
  - The build turns each pack into `assets/lang/<code>.js`, loaded only when that language is picked.
  - With `BW_INLINE=1` they're built into the page instead.
- **Fonts:** Tamil gets Baloo Thambi 2, the Tamil sister of our Baloo font. Chinese, Japanese and Korean get Noto Sans in that script. Each loads from Google Fonts only when its language is picked, and CJK arrives in small slices.
- **Missing strings:** `BramblewoodI18n.misses()` in the browser console lists every English string seen on screen with no translation yet. Use it as the to-do list.

## Adding or fixing translations

1. Add a row to `tools/i18n_core.py`, or edit `lang/<code>.json` directly. Hand edits survive re-running the script.
2. Run `python3 tools/i18n_core.py`, then the normal build.
3. Run `python3 tests/e2e/i18n.py`. It checks every pack loads, translates and switches back.
